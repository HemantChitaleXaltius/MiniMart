# MiniMart - Completed

This is the updated prototype for **Lab 1: Code Review Clinic**.

## Run it

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000.

Demo accounts: `admin / admin123` and `shopper / password1`.

Do not read `app.py` until the activity tells you to. Use the app, observe its behaviour, and record evidence first.
